# Master's Thesis — Automata Learning for Strategy Synthesis in Socially-Aware Autonomous Systems

📄 Full thesis (PDF, Politecnico di Milano — POLITesi): https://hdl.handle.net/10589/235888

## Summary
This thesis addresses the challenge of coordinating search-and-rescue (SAR) robots with 
untrained civilian responders ("zero responders") during large-scale evacuations. Building 
on the FormIDEAble framework, I developed an *adaptive-support strategy* using automata 
learning and Priced Timed Markov Decision Processes (PTMDPs) to dynamically model 
responder behavior, evaluated through agent-based simulations in NetLogo.

**Key techniques:** automata learning, formal verification, Markov Decision Processes, 
agent-based simulation

**Supervisors:** Prof. Livia Lestingi, Prof. Matteo Rossi — Politecnico di Milano
